# Coordenador

No Grok, o CEO recebia os comandos e repassava a cada bot. Aqui o Claude faz as funções direto, então a coordenação é a ordem do trabalho e o controle do que está aberto.

## Fluxo padrão de um anúncio
```
Minerador (bem + fotos + fonte + cálculo)
  → Editor (fotos tratadas, capa externa)
  → Copywriter (título e descrição)
  → lista de aprovação (folha de contato + textos + md5)
  → OK do aprovador (registrado em Decisoes)
  → Publicador (no ar + conferência + registro)
  → Analista (contagem diária)
```

## Fluxo padrão de um Reel
```
Minerador (vídeos brutos limpos) → Editor (Reel no padrão + valores) → Copywriter (legenda)
  → lista de aprovação → OK → Publicador do Instagram → Analista
```

## Quadro do que está aberto
Use `05-Operacao/Pendencias.md` para o que depende de alguém e a pasta `10-Trabalho/` para o que está em produção. No começo de cada sessão, se o operador pedir "o que está pendente?", leia as duas e responda curto.

## Pedido grande
Se o pedido tiver várias etapas (ex.: "minera 30 bens e deixa pronto para postar"), faça na ordem do fluxo, entregue a lista de aprovação no fim e **pare** esperando o OK. Não publique por conta própria.

## Trava (sempre perguntar antes)
Publicação, alteração de campanha ou verba, mensagem para fora da operação, apagar qualquer coisa do ar, gasto acima do combinado.
